This folder contains CSV files for Francis, O. (2026) ‘Quantified duplications of proteins within complexes across eukaryotes’. bioRxiv, p. 2026.02.23.705090. Available at: https://doi.org/10.64898/2026.02.23.705090.

- [Expanded_compOGs.csv](./Expanded_compOGs.csv) includes the species-specific expansions observed in the study.
- [Taxonomic_subset.csv](./Taxonomic_subset.csv) includes the taxa used in this study, including the genome accessions and contig count as a measure of genome fragmentation.
- [odb12v0_odb12v2_uCompOG_conversion.csv](odb12v0_odb12v2_uCompOG_conversion.csv) includes corresponding accessions required for mapping the repertoire outlined in this study, from OrthoDB version 12v0 to version 12v2.
